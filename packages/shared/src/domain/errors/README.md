# Errors

Shared error code registry and the `{ code, message, details? }` payload contract used by the backend `appError()` helper and the webapp `lib/errors` parser.

Isomorphic: no runtime dependencies, no Node/DOM APIs — import it from Convex functions and from the browser.

See [docs/developer/error-handling.md](../../../../../docs/developer/error-handling.md) for the conventions.
